# SignalLens v0.5.0

本版让分析依据可以直接回看，并新增结合证据的旁观者行动建议。

## 新增与修复

- 关键证据与互动窗口显示对应聊天正文、双方角色、时间和附近对话；长窗口优先展示相关两端，并标记省略部分。
- 关键消息按关系方向筛选、分页，显著证据、相反证据和待人工核对线索分别保留。
- 新增「旁观建议」，覆盖边界、关系后撤、共同投入、关心、关系性质和邀约落实；支持全面、恋爱、朋友、沟通目标与可选的相处感受。
- 每条建议提供观察、可能忽略的解释、下一步行动、沟通措辞、观察点和调整投入的条件，并可回看对应依据。
- 排除「最近」等常用词单独触发的个人回忆线索；修正主动重启计数，避免把其他互动事件当作主动联系。
- 报告包含旁观建议；默认匿名导出继续清理正文片段，未核对线索不会升级为已确认事实。
- Windows 打包后检查明确验证旁观建议模块；发布前核验 ZIP 的文件、版本、数据排除规则与 SHA256。

建议由本地规则消费已有分析结果生成，切换建议目标不增加 API 请求。本版不改变 Jev 九问、分析缓存 schema 或评分公式；建议是可选择的沟通行动，不预测对方感情、人格或关系结果。

## 下载与升级

下载 `SignalLens-v0.5.0-Windows-x64-portable.zip`，解压整个文件夹后双击 `SignalLens.exe`。无需安装 Python。

升级时先完全关闭旧版，备份旧目录中的整个 `data` 文件夹，再更新程序文件并保留原 `data`。API Key、分析缓存和好友档案都在这里；不要用空 `data` 覆盖旧数据。新版文件夹若与旧版分开，可在关闭旧版后把原 `data` 复制到新版程序旁。

ZIP 的校验值见同页 `.zip.sha256` 文件。首次运行第三方未签名程序可能出现 Windows SmartScreen 提示。
