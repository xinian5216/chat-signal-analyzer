# SignalLens v0.6.0

本版补齐模型版本与分析条件的追溯，并提供默认关闭的 Jev 1.14、图片与事件辅助实验入口。

## 新增与修复

- 默认固定 `jev-1.13.0`；在「分析设置」中可显式选择 `jev-1.14.0`。尚未完成真实中文效果对照，本版不宣称新版模型更准确。
- 文字缓存绑定完整问题定义、明确模型版本与上下文策略；移动模型别名不读写持久文字缓存。实际模型未知或版本不符时不缓存，明确版本不符按分析失败处理。
- 结果、报告与好友历史统计整批实际模型和分析条件。模型混用、不同分析条件或缺少来源的旧结果不能悄悄用于趋势比较；旧档案只在内存中重建来源，不改写历史快照。
- 可选「补充检索相关的较早聊天」：从本次导入、目标之前的原文按明确文字锚点补充最多 3 条 / 1200 字符，不包含未来消息。
- 可选「图片辅助分析」：逐图绑定、裁剪、遮挡、预览并确认上传。图片在本地纠正方向、合成透明像素、去除原始元数据并转成静态 PNG。未确认图片不发送，动画不抽帧，长截图要求先裁剪。图片判断独立展示，始终需人工核对，不自动计入评分或档案；导出仅含请求数量。
- 可选「事件语义辅助」：为现有待核对的拒绝回应、邀约推进、个人回忆候选提供闭集判断，每次分析最多额外 8 次请求。超额候选仍保留，辅助结果不自动确认事件。
- 固定已验证的 Streamlit 与 TypeSafe SDK 版本。Windows 冻结程序自检覆盖新增模块、合成 PNG 编解码、SDK 图片类型和事件问题构造，全程不调用真实 API。

所有实验功能默认关闭，只有点击「开始 Jev 分析」才可能发出请求。实验图片与事件请求可能增加 API 用量。九问语义、聚合公式和 `chat-signal-v3.3` 不变，报告导出继续零 API。

## 验证范围

离线测试与冻结程序自检验证实现、兼容性和隐私边界；虚构案例与模拟客户端不能证明真实模型准确率。新增 20 例冻结中文用例及零 API 计划检查，真实对照步骤见 [Jev 1.14 验证方案](../jev-upgrade.md)。

## 下载与升级

下载 `SignalLens-v0.6.0-Windows-x64-portable.zip`，解压整个文件夹后双击 `SignalLens.exe`，无需安装 Python。ZIP 的校验值见同页 `.zip.sha256` 文件。

升级前完全关闭旧版，并备份整个 `data` 文件夹；更新程序文件时保留原 `data`，不要用空目录覆盖。若解压到新目录，在关闭旧版后把原 `data` 复制到新程序旁。API Key、缓存与好友档案都保存在这里。

旧缓存文件不会删除；由于缓存条件变得完整，旧文字缓存不会自动命中新条件，重新分析可能增加 API 请求。旧档案仍可查看，缺少完整来源的历史比较会保守提示重新分析。
