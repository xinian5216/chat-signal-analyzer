# 脱敏规范（DEIDENTIFICATION）

目标：进入 field study 数据集的片段与标注**不含可识别个人身份的信息**，
也不含媒体内容。所有检查在数据冻结前完成。

## 可以进入数据集

| 字段 | 规则 |
|---|---|
| `item_id` | 随机、与内容无关，不可反推 |
| `group_id` | 聊天双方配对的随机 ID（同一双方的所有片段共享） |
| `text` | 脱敏后的纯文本；微信三行块/冒号格式均可，但发送者姓名一律替换 |
| `time_bucket` | 粗粒度：`early_morning` / `morning` / `afternoon` / `evening` / `late_night`；**禁止精确时间与日期** |
| `labels` | 标注状态与取值（见 `annotation_schema.json`） |
| `annotator_id` | 标注者随机 ID |

## 绝对禁止进入

- `raw_speaker`、真实昵称、备注名、头像描述、联系方式、电话号码；
- 邮箱 / 身份证 / 银行卡 / 精确地址 / 精确时间戳；
- 任何媒体内容（图片、语音、视频、文件）——只允许中性占位标记
  （如 `[发送了一张图片，内容未知]`），内容一律未知；
- 账号 ID、群名称、机构名称等可定位信息；
- 标注记录中的隐私字段（代码层白名单强制，见
  `field_study.py` 的 `ANNOTATION_FIELDS` / `FORBIDDEN_ANNOTATION_FIELDS`）。

## 处理流程

1. 参与者在研究者指导下自行删除或替换片段中的直接标识符；
2. 自动扫描（手机号、邮箱、身份证、URL、长数字）复核；
3. 研究者人工抽查 10%（至少 5 条）确认无可识别信息；
4. 通过后写入冻结清单（SHA256）方可进入分析。

## 角色与访问

- 观察标注者只见脱敏文本与 `item_id`，不见 `group_id` 与参与者信息；
- 分组划分仅研究者持有，盲测集结果产生前不对标注者暴露集别。
